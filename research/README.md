# 幸存者偏差研究脚本

主回测的股票池是**今天的** S&P 500 + 纳指100，不含后来被淘汰/退市的公司，收益被高估。这里是量化偏差大小的一次性分析脚本，**不属于主回测流程**，结果没有用在 `results/` 和报告页面的主数字里。

数据都放在仓库之外（不要提交）。运行方式见每个脚本开头；下载的文件请放进各自新建的空目录，并用 `python3 -I` 运行。

| 脚本 | 做什么 | 输入 |
|---|---|---|
| `01_index_turnover.py` | 2004 年以来进过 S&P 500 的代码数、被剔除的数量、2008/2015 年幸存比例 | [历史成分股](https://raw.githubusercontent.com/fja05680/sp500/master/S%26P%20500%20Historical%20Components%20%26%20Changes%20(Updated).csv) |
| `02_yahoo_coverage_of_delisted.py` | 用 yfinance 测试被剔除公司的价格有多少能找回 | 上一步输出的 json |
| `03_momentum_on_pit_universe.py` | 逐年统计缺多少公司；12 个月动量 Top 10 在三种股票池下的年化 | 以上两步的输出 |
| `04_strategies_on_pit_universe.py` | 主要打法在三种股票池下的对比 | 同上 |
| `05_french_momentum_anchor.py` | 肯·弗伦奇（CRSP，含退市股）的动量十档组合，作为无偏差锚点 | [10_Portfolios_Prior_12_2_CSV.zip](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/10_Portfolios_Prior_12_2_CSV.zip) |

`03`、`04` 里的 B、C 两种口径带有"股票入选指数之后才能买"的限制，仅用于**诊断偏差大小**。用户明确表示不要在正式结果里用这个限制。

## 主要结论（2004–2026）
- 2004 年以来进过指数的代码 993 个，其中 490 个（49%）今天已不在；2008 年初的成分股只有 49% 还在。
- Yahoo 只能找回 186/490 个被剔除代码的价格，按在指数里的天数加权仅覆盖 26%。
- 12 个月动量 Top 10：今天的成分股 39.9% 年化；当时的成分股并补回找得到的退市股后 12.6%；肯·弗伦奇最强一档 13.5%（价值加权）/ 9.4%（等权）。
- "52 周新高 + 8 倍 ATR" 在原回测最好（16.1%），在更真实的股票池里只剩 5.0%。
